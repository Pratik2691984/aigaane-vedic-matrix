# Public terms (everyone-safe)

English first. IAST in parentheses. These are the forms used on aigaane.in.

## Corrections applied

| Avoid | Use |
|---|---|
| Annamāya as “digestive fire” | Digestive system (**annavaha** / **jatharāgni**). **Annamaya kośa** is the food sheath, not the fire. |
| Hṛṛaya / Hrdaya misspelling | **hṛdaya** |
| dosa | **doṣa** (vāta, pitta, kapha) |
| Śrāddhā for trust | **śraddhā** (trust/faith). **śrāddha** is the funeral rite — do not mix. |
| Raga-dvesa | **rāga–dveṣa** |
| Shruti / Sruti informal only | **śruti** (IAST), “śruti” on first use |
| Sushumna / Susumna | **Suṣumṇā** |
| Ida / Pingala | **Iḍā**, **Piṅgalā** |
| tala / Tala Dashapranas | **tāla daśaprāṇa** |
| Prastara / Meru Prastara | **prastāra**, **meru-prastāra** |
| Sanyoga | **saṃyoga** |
| Virahanka informal | **Virahaṅka** |
| tanpura drone copy | **tānpūrā** (common public: tanpura) |
| Base Sa | **ādhāra ṣaḍja** |
| vilambit / drut | **vilambita**, **madhya**, **druta** |
| vadi-samvadi | **vādī–saṃvādī** |
| 7 shuddha + 5 vikrit | **7 śuddha + 5 vikṛta** |
| Chandas | **chandas** (metre) |
| Rasa as “juice” only | **rasa** — aesthetic flavour (Nāṭyaśāstra); also nutrient fluid in Āyurveda. Label which sense. |

## 22 śruti names (public list)

Kṣobhinī, Tīvrā, Kumudvatī, Mandā, Chandovatī, Dayāvatī, Rañjanī, Raktikā, Raudrī, Krodhā, Vajrikā, Prasāriṇī, Prīti, Mārjanī, Kṣiti, Raktā, Sandīpanī, Ālāpinī, Madantī, Rohiṇī, Ramyā, Ugrā.

Traditional lists vary by school. This set is the common teaching list, not a claim of a single closed canon.

## Physiology

Keep biomedical names in English when addressing a general audience (vagus nerve, HPA axis, HRV RMSSD). Put Sanskrit only where it is a real term of art, never as decoration on a lab metric.
